# CLAUDE.md

This project keeps a single rulebook for all AI coding agents.

## → Read [AGENTS.md](./AGENTS.md) first, every session.

`AGENTS.md` contains the hard rules, the layer responsibilities, the document
map, the commands, and the definition of done. It is the single source of truth
— rules are intentionally **not** duplicated here, to prevent drift.
